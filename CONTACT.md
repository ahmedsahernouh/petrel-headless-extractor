Desktop: open Help > About Field Viewer for clickable contact links.
Help > Check for updates is the third menu item. It checks public GitHub releases
when clicked, in the background, without sending project files, paths or logs.
It reports newer, current, newer-than-public, no eligible release, or unable to
check. Beta versions include published beta releases; stable versions check stable
releases. The release link opens only when clicked; no automatic download/install.
An offline, rate-limited or incomplete check never means that you are up to date.
Local preparation revisions (r9/r10) are not separate public version numbers;
publish a new version tag when users need to detect a newer distributed build.
