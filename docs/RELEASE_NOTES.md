Field Viewer is the publicly released, open-source extraction component of a
larger, non-public project. This repository and download contain the standalone
extractor. The GUI is an unpublished preview for a future release.

## Scope

The beta recovers supported native logs, surface grids, points, polygons,
trajectories, well-head evidence and readable workflow definitions. Supported
local ZGY can be converted to SEG-Y with numerical and geometry checks.
Source project files remain read-only; reports distinguish recovered, empty,
unsupported, missing and rejected objects.

Coverage is limited to tested binary profiles. Unknown units, CRS, datum and
seismic axes remain explicit; values are not silently rescaled. Complete
reservoir/RESCUE models are unsupported. Readable workflows are not executed or
qualified for native reimport. Check formats, units and CRS when importing
exports into other applications. Large outputs can require substantial storage
and processing time. Exit 10 means completion with disclosed gaps.
