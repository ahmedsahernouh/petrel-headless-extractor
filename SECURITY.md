# Reporting a security issue

Use [GitHub's private reporting form](https://github.com/ahmedsahernouh/petrel-headless-extractor/security/advisories/new)
or email [ahmed-saher@hotmail.com](mailto:ahmed-saher@hotmail.com) with the subject
**Field Viewer security report**.

Include the application version, a description of the issue and a minimal
reproduction if available. An anonymized example helps keep project data private.
We can agree on any additional material needed after the initial report.

Ordinary extraction problems and feature suggestions are welcome in
[GitHub issues](https://github.com/ahmedsahernouh/petrel-headless-extractor/issues).
