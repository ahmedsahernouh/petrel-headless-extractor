# Field Viewer Data Extractor - Beta 3

Standalone Windows tool for recovering supported Petrel project data and metadata
into open files, with reports, source/output hashes and QC. Source projects remain
read-only. No Petrel process or Ocean license is required.

Start with Start Here.html or Start Here.pdf. Desktop users open
FieldViewer_Desktop.bat; CLI users use FieldViewer_data_extractor.bat. Choose Full
extraction, Report only, or CRS and datum only. Public beta3 does not export RESCUE
models; the CLI inventory-only route reports source-grid metadata.

Help > About has contact links; Help > Check for updates checks public releases.
See RELEASE_NOTES.md and KNOWN_LIMITATIONS.md for tested scope and gaps.
